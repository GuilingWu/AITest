# 竖屏 3D 拼图游戏 Spec

## 1. 项目概述
- 目标产品：移动端竖屏 3D 拼图游戏
- 核心玩法：把一张图片切分为 `M x N` 的立体拼图块，玩家通过拖拽、旋转、拼合完成整图
- 目标平台：Godot 4.2+ Mono，C#，iOS / Android
- 交互重点：拖拽流畅、90 度旋转、自动拼合、组合体继续可操作

## 2. 核心需求摘要
- 输入一张图片，按参数 `M` 行、`N` 列、厚度 `H` 生成对应数量的 3D 拼图块
- 拼图块初始可被打乱顺序，并可按 `90 * n` 度旋转
- 拼图块可在堆放区自由摆放，堆放区支持滑动列表模式或重叠堆叠模式
- 玩家可将图块从堆放区拖拽到拼图区
- 点击图块或组合体后顺时针旋转 90 度
- 相邻图块在位置正确且旋转角度一致时自动拼合
- 拼合后的组合体仍可像单块一样拖拽、点击旋转
- 完成拼图后进入结算界面，展示本次难度星级

## 3. 用户流程
1. 进入主题选择界面
2. 选择内置主题或从相册导入图片
3. 进入图片选择界面，查看已完成状态和历史最高星级
4. 进入难度设置界面，配置行列数、旋转打乱、堆放方式
5. 进入拼图主界面完成拖拽、旋转、拼合
6. 拼图完成后进入结算界面，展示评分并记录进度

## 4. 界面需求

### 4.1 主题选择界面
- 展示内置主题，如动物、风景、建筑
- 每个主题显示对应拼图进度
- 提供“从相册选择”入口
- 点击主题进入图片选择界面
- 点击相册入口后选择本地图片并进入难度设置界面

### 4.2 图片选择界面
- 展示当前主题下的图片列表
- 区分已拼过与未拼过的图片状态
- 已完成图片显示历史最高星级
- 点击图片后进入难度设置界面

### 4.3 难度设置界面
- 可设置拼图切分行数 `M`
- 可设置拼图切分列数 `N`
- 可配置是否打乱旋转方向
- 可配置是否使用滑动列表整理排列
- 需要实时显示当前配置对应的难度星级
- 点击开始后进入拼图界面

### 4.4 拼图界面
- 上半区为拼图区
- 下半区为堆放区
- 堆放区支持两种模式：
  - 滑动列表模式：图块以横向列表形式展示并打乱顺序
  - 堆叠区域模式：图块在可选区域内重叠堆放
- 支持从堆放区拖拽图块到拼图区
- 支持在拼图区中继续拖拽单块或组合体
- 支持点击旋转单块或组合体
- 支持满足条件后自动拼合

### 4.5 完成界面
- 展示本局获得的星级评分
- 提供继续挑战或返回上层界面的入口
- 记录完成状态和最佳成绩

## 5. 玩法规则

### 5.1 拼图块生成
- 输入：图片资源、行数 `M`、列数 `N`、厚度 `H`
- 输出：`M * N` 个带厚度的 3D 拼图块
- 每个拼图块需正确映射原图对应区域

### 5.2 拖拽规则
- 图块可从堆放区拖到拼图区
- 图块进入拼图区后可继续移动
- 组合体生成后应继承同样的拖拽能力

### 5.3 旋转规则
- 点击图块时顺时针旋转 90 度
- 点击组合体时整体顺时针旋转 90 度
- 旋转状态以 0 / 90 / 180 / 270 度循环

### 5.4 拼合规则
- 仅当相邻图块位置关系正确时允许拼合
- 仅当待拼合图块旋转角度一致时允许拼合
- 拼合成功后生成组合体
- 组合体可继续与其他图块或组合体拼合

### 5.5 完成判定
- 所有图块均已正确放置并组成完整图片时判定完成
- 完成后立即进入结算界面

## 6. 难度与评分

### 6.1 星级规则
- 基础难度按行列规模决定：
  - 简单：1 星
  - 中等：2 星
  - 难：3 星
- 旋转打乱开启：额外 `+1` 星
- 堆叠排列开启：额外 `+1` 星
- 总星级上限为 5 星

### 6.2 难度示例
- `3x3`，无旋转打乱，滑动列表：1 星
- `4x4`，无旋转打乱，滑动列表：2 星
- `5x5`，无旋转打乱，滑动列表：3 星
- 在上述基础上，开启旋转打乱可额外加 1 星
- 使用堆叠区域模式可额外再加 1 星

## 7. 数据记录
- 保存主题维度的完成进度
- 保存单张图片是否完成
- 保存每张图片历史最高星级
- 保存用户从相册导入的图片记录

## 8. 非功能要求
- 游戏必须为竖屏布局
- 拖拽和点击反馈需要足够流畅
- 拼图块数量增大时仍需保持可接受的性能
- 触屏操作区域需要适配移动端使用习惯

## 9. 边界与约束
- 行列参数需要限制在合理范围内，避免块数失控
- 自定义图片加载失败时需要有兜底提示
- 相册访问需要处理移动端权限问题
- 堆叠模式下允许图块视觉重叠，但仍需保证可选中与可拖拽

## 10. 待明确问题
- 厚度 `H` 是否固定为默认值，还是允许在高级设置中配置
- 拼图区是否需要吸附网格或自动对齐辅助
- 已完成图片重新挑战后，是否覆盖原记录还是仅在更高星级时更新
- 堆叠区域中图块的选中优先级如何定义
